# Release History

Commit prefixes follow the [Conventional Commits](https://www.conventionalcommits.org) specification:

- `feat:` — new feature → bumps **MINOR**
- `fix:` — bug fix → bumps **PATCH**
- `chore:` / `docs:` / `refactor:` / `ci:` etc. → bumps **PATCH**
- `feat!:` / `fix!:` / `type!:` — breaking change → bumps **MAJOR**
